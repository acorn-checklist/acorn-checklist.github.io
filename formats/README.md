# ACORN in other formats

Fillable versions of the ACORN checklist, generated from `checklist/checklist.yaml`:

- `acorn-checklist.docx`: Word.
- `acorn-checklist.tex`: LaTeX (compiles with pdflatex). Include it in supplementary material or adapt it.
- `acorn-checklist.Rmd`: R Markdown. Knits to HTML, Word or PDF. Tick boxes by replacing `[ ]` with `[x]`.

Do not edit these files by hand. Change `checklist/checklist.yaml` and run `python scripts/build_formats.py`.
